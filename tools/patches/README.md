# Patch scripts and tests (history)

Each folder is one session's patch scripts and tests (S24 to S51), imported oldest first, one commit and one tag each (`patches-<name>`).

These are history. Once a widget lives in git, the next change is an ordinary commit on the tagged live version, not a new patch script. The tests are worth keeping and running on every build.
